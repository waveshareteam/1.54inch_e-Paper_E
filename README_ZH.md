# Waveshare 1.54inch e-Paper (E) 产品工程示例程序

[English](README.md)

1.54inch e-Paper (E) 是一款分辨率为 240 x 240 的全彩电子墨水屏，采用 SPI 通信接口，具有低功耗、宽视角和断电保持最后一屏显示内容等特点。模块版可通过 SPI 接口，接入 Raspberry Pi、Arduino、STM32、ESP32 等主控板。

- [购买链接](https://www.waveshare.net/shop/1.54inch-e-Paper-E.htm)
- [产品文档](https://docs.waveshare.net/1.54inch_e-Paper_E)
